# Quant-Summer-Project Docs Index

A quantitative finance portfolio project. See the [root README](../README.md) for the project description, how to run it, and a results summary.

This folder holds the supporting documentation:

- **[roadmap.md](roadmap.md)**, week by week plan and current completion status (checkboxes reflect what's actually done, not just planned).
- **[decisions_log.md](decisions_log.md)**, running record of every decision that isn't obvious and why it was made. Start here to understand *why* the code looks the way it does.
- **[math_reference.md](math_reference.md)**, formulas used throughout, with notes wherever the actual implementation deliberately deviates from the original plan.
- **[data_sources.md](data_sources.md)**, Open-Meteo and Polymarket API details, known rate limit behavior, and the (settled) historical spread data gap.
- **[project_structure.md](project_structure.md)**, full repo layout with what each file actually does.
